# VNメモ帳（ビジュアルノベルメモ帳）

A visual novel script builder for RPGEN.

https://rpgja.github.io/rpgen-novel/


## 概要 / Overview

**VNメモ帳（ビジュアルノベルメモ帳）** は、RPGEN（ロールプレイングゲームエンジン）で動作するビジュアルノベルゲームのイベントスクリプトを作るためのWebアプリです。

### 特徴 / Features

- **タイムラインエディタ**: 会話、待機、キャラクターアクション、選択肢分岐などのコマンドをビジュアルに組み立て・並び替えできます。
- **インタラクティブプレビュー**: 作成中のスクリプトを、実際のノベルゲームのように再生して、キャラクターの動きや選択肢分岐の動作確認が可能です。
- **キャラクター管理**: ID、表示座標、デフォルト画像、および表情ごとの画像URL（Imgur等）を定義・管理できます。
- **分岐のネスト対応**: 選択肢コマンドの中に、それぞれ独自のコマンドタイムラインを配置できるため、複雑なストーリー分岐も表現できます。
- **Undo / Redo機能**: コマンドやキャラクターの編集履歴を履歴スタックで管理し、元に戻したりやり直したりできます。
- **インポート / エクスポート**: 作成中の状態を JSON ファイルで保存し、いつでも再開できます。
- **ワンクリックコンパイル**: 最終的なRPGENイベントコードをリアルタイム生成。立ち絵のプリロード命令（チラつき防止）も自動で挿入されます。
- **マニュアル・サンプル完備**: 使い方マニュアルや、プリセットストーリー（モモイ、ミドリなど）ですぐにテストできます。

## 環境構築 / Getting Started

1. [Volta をインストール](https://docs.volta.sh/guide/getting-started)
2. このリポジトリをローカルにクローン
3. [pnpm をインストール](https://pnpm.io/ja/installation)
4. この `README.md` があるディレクトリを VS Code で開く
5. 拡張機能タブから推奨拡張をインストール
7. `pnpm i` を実行して依存関係をインストール
8. よく使うコマンド:
   - `pnpm run dev` — 開発ビルド
   - `pnpm run prod` — 本番ビルド (または `pnpm run build`)
